# MemRW3 · 调参工作区

嵌入式 MCU 变量监控与调试工具，支持 J-Link、CMSIS-DAP、ST-Link 等探针，可同时查看实时曲线和类似 Keil Watch 的变量表。

本仓库基于 [SuperLiaohy/MemRW3](https://github.com/SuperLiaohy/MemRW3) 的 v2.2.1（`c47c29403af1e1295403b415115a93de41f84f57`）进行增强。当前沿用 **Enhanced Pink** 功能基线，增加可调透明背景、三分区工作区与调参记录，保留 Watch 变量表、完整采样历史和原程序图标。原有 Debug 调试器继续可用；源码修改、Keil 后台编译以及后来增加的编译/烧录/开始快捷键已撤回。

## 当前唯一程序

运行 `dist/MemRW3/MemRW3.exe`，或使用已更新的桌面快捷方式。本地旧版本程序副本已清理；源码与调参配置保留。当前使用图片背景替代旧初音装饰，操作与验证见 [工作区与调参优化](docs/工作区与调参优化.md)。

## 工作区与调参优化

背景设置可调整图片显示强度和面板不透明度。右键变量名或点击“加入图表”即可画曲线；图表支持 A/B 区间统计和历史 CSV 导出，工具栏可查看手工/AI 参数修改记录。背景强度和面板不透明度调整后自动记住，下次启动恢复，加载调参 JSON 不覆盖本机外观；布局仍随 JSON 配置保存。

## 界面优化说明

当前程序位于 `dist/MemRW3/`。支持中文注释分列、拖拽列宽和外置曲线列表，保留粉色主题。操作、配置迁移与修改文件见 [UI优化说明](docs/UI优化说明.md)，实际检查结果见 [UI优化验证记录](docs/UI优化验证记录.md)。

## Codex 默认读写

当前新版位于 `dist/MemRW3/`。启动即自动提供Codex接口，全部已加载数值变量默认可读写，无需AI开关、参数勾选、白名单或范围授权。原有表格、图表、PID会话与回滚功能保留。使用和验证见 [默认AI读写说明](docs/默认AI读写说明.md)。

## 通用 PID 在线调试

当前PID版包含在 `dist/MemRW3/`，MCP共14个工具。支持显式绑定Kp/Ki/Kd和目标/反馈/输出、保存基线、单项试调、观察接受与条件回滚，不绑定具体轴。接口、流程、实时性、安全与实机边界见 [PID在线调试方案](docs/PID在线调试方案.md)。

## 功能

| 功能 | 当前行为 |
|---|---|
| 实时曲线 | 多变量叠加、坐标缩放、游标、FFT；默认保留本次采集的全部历史 |

## Windows 一键安装

从 [Releases](https://github.com/Sering-Hong/MemRW3/releases) 下载 `MemRW3-Setup-2.2.1-pink.1-x64.exe`，双击后点击“安装”。安装前自动检测系统、实际 DLL 依赖和图形初始化；缺少依赖时停止并显示处理方法。自动创建粉色桌面、开始菜单及卸载入口。首次优先安装到 `D:\MemRW3`，也可更改目录。详见[安装说明](docs/安装说明.md)。

## 第一次使用

1. Windows 便携版解压后运行 `MemRW3.exe`。本地部署目录为 `D:\MemRW3`。
2. 在设置中选择正确 MCU、探针协议与速度，连接已上电的目标板。
3. 点击“打开变量树”，加载与板上固件对应且含 DWARF 调试信息的 `.axf` 或 `.elf`。
4. 将需要的标量添加到 Chart，将标量、结构体或数组添加到 Table。
5. 点击控制栏“开始”。要同时看表格和曲线，将 Table **Pop out** 后切回 Chart。
6. 点击“暂停”结束这段采集，用“查看全部”回看全过程。持久保存前先设置 CSV 文件。

开始与继续采集会覆盖所选的同一个 CSV 文件，请为每段需要保存的记录选择不同路径。曲线完整历史保存在内存中，关闭程序后不会自动恢复；保存配置也不保存采样点。

## 从源码构建

使用当前稳定版 Rust，保留 `Cargo.lock`。项目采用 Rust 2024 edition；`Cargo.toml` 中声明的 1.85 是项目最低声明值，锁定的依赖可能需要更高版本，不能据此保证 Rust 1.85 可编译。当前 Windows 实际验证工具链为 Rust 1.99.1 / GNU。

```bash
git clone https://github.com/Sering-Hong/MemRW3.git
cd MemRW3
cargo build --release --locked
cargo test --release --locked
cargo run --release --locked
```

Windows 输出 `target/release/MemRW3.exe`；Linux/macOS 输出 `target/release/MemRW3`。系统依赖和 Windows 安装包制作见[构建文档](docs/构建与打包.md)。

## 验证与限制

完整历史的回归测试连续写入 120000 个点，检查起始与结束点都存在；绘制压缩测试覆盖首尾点、尖峰和时间顺序。Watch 包含搜索与无硬件 UI 测试。恢复后的测试结果见[版本记录](CHANGELOG.md)。

软件测试不能代替目标板验证。硬件变量读写、探针连接、烧录及长时实测需要在相应 MCU 上确认；实际采样速度受探针、总线、变量数量和目标状态影响。完整历史会持续占用内存，高采样率和多曲线场景应监控内存并保存 CSV。
