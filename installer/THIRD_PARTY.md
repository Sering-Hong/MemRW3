# 安装器第三方组件

本项目使用 Inno Setup 构建 Windows 安装器。Inno Setup 的许可见 [InnoSetup-LICENSE.txt](InnoSetup-LICENSE.txt)，编译器本身不随应用安装。

`ChineseSimplified.isl` 来自 [jrsoftware/issrc is-6_7_3](https://github.com/jrsoftware/issrc/blob/is-6_7_3/Files/Languages/Unofficial/ChineseSimplified.isl)，原作者及翻译维护者信息保留在文件头。

应用图标及 MemRW3 源码的来源见仓库 README；这里的许可文件只对应安装器组件。
