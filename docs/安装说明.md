# MemRW3 一键安装说明

适用安装包：`MemRW3-Setup-2.2.1-pink.1-x64.exe`。程序功能以 Enhanced Pink 为基线，保留 Watch 变量表、完整曲线历史、粉色图标和原有 Debug 调试器。

## 1. 下载和安装

1. 打开 [GitHub Releases](https://github.com/RP27-EC/MemRW3/releases)，下载名称含 `Setup`、以 `.exe` 结尾的安装包。不要把 GitHub 的 Source code ZIP 当作安装包。
2. 双击安装包，确认安装目录。存在 D 盘时首次默认 `D:\MemRW3`，没有 D 盘时默认当前用户的 `%LOCALAPPDATA%\Programs\MemRW3`；升级通常沿用上次的目录。
3. 点击“安装”。安装程序先检查运行环境，通过后复制文件并创建粉色桌面快捷方式、开始菜单入口和卸载入口。
4. 完成后可立即启动，也可通过桌面 `MemRW3` 打开。

安装包包含程序及使用、技术、安装说明，安装过程不需要联网下载程序组件。使用者无需安装 Rust、Python、Git、Keil 或 Inno Setup。缺失系统依赖时按提示修复后重试。

安装到当前用户可写目录时不要求管理员权限；如果自行选择受保护目录，系统可能拒绝写入，应改选可写目录或使用有相应权限的账户。当前安装包未做代码签名，Windows 可能显示发布者未验证。

## 2. 安装前检测内容

| 检测项目 | 检测方式 | 不满足时 |
|---|---|---|
| 系统版本 | 安装器检查 Windows 10 1809 或更新系统，支持 Windows 11 | 显示不支持的系统并退出 |
| 系统架构 | 此安装包支持 x64，不支持 32 位和 ARM64 | 显示架构/系统错误并退出 |
| 当前程序的 DLL 依赖 | 构建时读取实际 EXE 的 PE 导入表，安装前由 x64 检查器逐个加载 | 列出缺少或无法加载的 DLL 与 Windows 错误码，停止安装 |
| UCRT / 系统组件 | 按实际导入的 `api-ms-win-*`、系统 DLL 检查，不以某个注册表键代替 | 提示通过 Windows 更新或系统修复处理 |
| VC++ 运行库 | 仅当该构建实际导入 VCRUNTIME / MSVCP 等 DLL 时成为必需依赖 | 提示安装 Microsoft 官方 x64 运行库 |
| 图形初始化 | 用包内同一份 MemRW3.exe 启动隐藏的独立渲染自检，使用程序默认的 eframe 渲染器 | 提示更新显卡驱动、Windows 或检查远程/虚拟机图形环境 |
| 检测超时/异常 | 最多等待图形自检 60 秒，异常退出也视为失败 | 停止安装并记录报告 |

API-set 名称通过 Windows 加载器解析，不要求系统目录中存在同名物理文件，避免把正常系统误判为缺 DLL。当前 Windows GNU 构建通常只依赖系统组件；MSVC 构建可能需要 VC++ 运行库，安装器随实际程序生成依赖清单。

图形自检不会创建 MemRW3 采集会话，也不会连接探针、访问目标板、烧录或采样。它检查安装时的运行环境；以后更新驱动、切换显示环境或损坏系统组件仍可能影响运行。

## 3. 缺少依赖时如何处理

失败后安装页面会保留错误信息，程序文件尚未安装。报告保存到：

```text
%LOCALAPPDATA%\MemRW3\install-dependencies.txt
```

修复后可在安装页面重试，或关闭后重新运行安装包。

- 缺少 `api-ms-win-*`、`ucrtbase.dll` 或系统 DLL：先完成 Windows 更新，必要时由系统维护人员修复组件；不要从不明 DLL 网站单独复制文件。
- 缺少 `VCRUNTIME140*.dll`、`MSVCP140*.dll`：使用 [Microsoft 官方运行库说明](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)，下载并安装 [x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。
- 图形初始化失败：安装显卡厂商正式驱动，更新 Windows；远程桌面或虚拟机需要可用的图形加速。安装器测试的是实际渲染器，安装旧版 DirectX 离线包不一定能解决。
- 无法启动检查器或报告文件无法写入：检查安全软件拦截、临时目录权限和磁盘空间。
- 安装目录不可写：改选当前用户可写目录。

安装程序只检测并提醒，不会未经选择自动安装系统运行库或替换驱动。

## 4. 探针驱动和固件文件

J-Link、ST-Link、CMSIS-DAP 的驱动要求取决于具体设备、接口与固件。安装软件时允许未插探针，不会把“没有探针”误报成依赖缺失；连接目标时再按实际硬件安装厂商驱动或配置对应 WinUSB/HID 接口。

驱动入口：[SEGGER J-Link](https://www.segger.com/downloads/jlink/)、[ST-LINK USB 驱动](https://www.st.com/en/development-tools/stsw-link009.html)。CMSIS-DAP 请依据具体探针说明使用相应接口；不要把所有接口统一替换为同一种驱动。

查看变量还需要与板上固件一致、包含 DWARF 信息的 ELF/AXF，这属于用户工程文件，不随安装包分发。Keil 只在外部编辑、编译固件时使用，不是启动 MemRW3 的必需依赖。

## 5. 升级、目录和卸载

升级前暂停采样、保存 CSV 并退出程序，再运行新安装包选择原目录。安装器会检查环境并更新已分发的程序文件；如果程序占用文件，会按安装界面提示处理。

安装器仅分发程序、图标、通用说明和环境检测工具。它不覆盖 `source` 源码仓库，不打包个人固件、配置和 CSV。重要记录建议放在独立的数据目录；不要用安装目录内的同名发布文件保存自己的记录。

通过 Windows“已安装的应用”中的 MemRW3、开始菜单“卸载 MemRW3”，或安装目录的 `unins000.exe` 卸载。卸载按安装记录删除分发文件和本次创建的快捷方式，不递归清空整个目录；额外的用户文件、源码仓库和依赖检查报告保留。

本机已有 `D:\MemRW3\source` Git 仓库可以继续使用，与安装器的程序文件管理互不冲突。

## 6. 无人值守安装

普通用户双击 EXE 即可。批量部署时可使用：

```powershell
.\MemRW3-Setup-2.2.1-pink.1-x64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="D:\MemRW3" /LOG="setup.log"
```

静默安装同样执行依赖与图形检测，不提供绕过检查的开关。执行环境需要能够初始化图形后端；纯无图形会话可能失败。失败时退出码非零，不应把进程创建成功视为安装成功。

测试或不希望创建快捷方式时可加 `/MERGETASKS="!desktopicon,!startmenuicon"`。请用进程等待方式收集退出码，双击运行不需要这些参数。

## 7. 安装包构建与验证

维护者需要 Windows、Python 3.10+、Rust、Inno Setup 6.5+，以及 x64 GCC 或 MSVC C++ 工具链：

```powershell
python .\tools\build_installer.py
```

脚本先调用现有便携包构建/测试流程，再读取实际 EXE 导入表，编译只依赖 `kernel32.dll` 和 `shell32.dll` 的检查引导器，在本机执行 DLL 与图形自检，通过后编译中文安装包并生成 SHA256。输出目录为 `dist\installer`。

已完成当前源码的便携包构建、测试时，可执行：

```powershell
python .\tools\build_installer.py --skip-portable --iscc "C:\path\ISCC.exe" --cc "C:\path\gcc.exe"
```

`--skip-portable` 要求调用者确认现有便携包与当前源码一致；安装包构建仍会执行运行依赖及图形检查。MSVC 环境可自动通过 Visual Studio Installer 的 vswhere 定位 `vcvars64.bat`，也可用 `--cc` 指定它。

安装器脚本在 `installer/MemRW3.iss`，依赖引导器在 `installer/check_runtime.c`，渲染检测入口在 `src/install_check.rs`。简体中文翻译保留自 [Inno Setup 官方源码 is-6_7_3](https://github.com/jrsoftware/issrc/blob/is-6_7_3/Files/Languages/Unofficial/ChineseSimplified.isl) 的作者说明。

Windows CI 会构建安装包并上传为 Actions 附件。GitHub Releases 分发已验证的安装 EXE 与校验文件；源码仓库保留构建脚本和说明，不直接提交大型安装二进制。
