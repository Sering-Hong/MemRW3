# Codex 读取 MemRW3 实施计划

目标：让 Codex 查询当前软件的变量、最新已采集值和 Chart 历史；不开放写入、连接/复位/烧录或原始地址读取。

实现选择：沿用 Rust/egui，新增仅监听 127.0.0.1 随机端口的按请求只读服务；Python 标准库 MCP stdio 桥接。GUI 主线程回答查询，后台线程只做传输，不触碰探针。无新增依赖。按用户明确执行要求直接实施，常规设计选择自主决定。

- [x] 本地服务：软件顶部“AI只读”开关，默认关闭；每次启用独立令牌与会话，停止/退出清理会话文件；认证、请求大小、超时和队列限制。
- [x] 数据接口：状态、分页变量列表、批量最新值、指定变量最近历史。保留中文注释、原始字节、数据类型和精确整数；时间说明区分采样相对时间与主机观察时间，未采集/断开/暂停标明状态。
- [x] MCP：list_sessions/get_status/list_variables/read_variables/get_history；多个实例必须明确选择。未知工具和所有写入请求拒绝。
- [x] 验证：无探针 Rust/Python 测试，覆盖拒绝写入、认证、过期状态、64位整数、注释映射、历史限量及协议握手；复用原项目锁定依赖的 GNU 构建方式。
- [x] 交付：独立 EXE 和桥接脚本，配置本机 Codex MCP，验证注册与实际只读调用；不覆盖原安装版。若当前聊天未热加载，明确说明重开会话或使用脚本命令读取。

限制：只能查询软件已加载的变量及已采集的数据；接口不会主动向 MCU 发读写命令。完整历史留在软件中，单次历史响应最多10000点。读值返回界面线程观察时间，不假称为精确硬件采样时刻。

实际验证与已知边界见 `Codex只读接入.md`；当前聊天未热加载原生工具，已验证脚本读取替代路径。
