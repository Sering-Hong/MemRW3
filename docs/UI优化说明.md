# MemRW3 界面优化说明

## 启动与边界

独立程序：`dist/MemRW3-ui-enhanced/MemRW3.exe`，直接双击启动。本轮不覆盖安装版、桌面快捷方式或三份镖架配置。界面优化不要求修改固件或重新生成 AXF。

本轮保留采集线程、内存读写、调试、CSV、FFT 和原始历史数据通路。显示压缩只用于绘图，不替换原始采样。全程不连接探针、不操作 MCU。

## 参数表

- 顺序：采集、参数名称、中文注释、类型、地址、当前值、刷新频率、写入值、操作。
- 树形分组保留显示名；叶子显示原字段短名。悬浮参数名称查看完整路径，右键复制完整路径；注释与当前值同样支持悬浮全文和右键复制。
- 双击中文注释编辑，Enter 或离开输入框确认，Escape 取消。该编辑仅改变界面配置，保存 JSON 后持久化，不产生变量写入请求。
- 拖动表头竖分隔线调整列宽；双击按展开内容适配；“恢复默认列宽”复位。默认名称/注释/当前值宽度分别为 240/360/180 逻辑像素。横向滚动查看右侧列，纵向滚动保留表头。
- 主窗口和 Pop out 窗口分别保存列宽，跟随配置 JSON 保存和加载。
- 搜索支持名称、完整变量路径、中文注释与十六进制地址。新增变量时显示名与注释分别填写。
- 写入仍需使用“写入值”输入框的 Enter 或“写入”按钮，并执行既有类型和范围校验。

## 配置兼容

Table 节点新增可选字段 `comment`。旧配置没有该字段时，仅以两侧有空格的 ` ｜ ` 或 ` | ` 拆分旧显示名；左侧保留显示名，右侧迁为注释。普通 `a|b` 表达式不拆分。显式 `"comment": ""` 保持空注释，不重复生成。

变量 `source_name`、地址、类型和大小不因迁移而改变。原来的扁平 Table 配置也继续支持。新增 `main_widths` / `popout_widths` 缺失时采用默认列宽，非法长度、非有限宽度及过小/过大宽度按默认值或边界处理。

Chart 新增轴模式及曲线列表开关的配置保存；旧配置默认完整历史、显示曲线列表。旧界面预览版本中多余的装饰配置字段会被忽略。

## 图表

- 默认“完整历史”；“最近时间窗”初始 10 秒，可输入其他正数秒数，Enter 或离开输入框后应用合法值。“查看全部”回到完整历史，不删除采样。
- 曲线列表位于图表右侧，可用工具栏“曲线列表”收起，拖动左边界改变宽度。点击名称或勾选框切换显隐；名称悬浮显示全文；右键名称打开曲线属性入口。列表同时显示最后采样值。
- 工具栏随窗口宽度换行。轴范围采用持续编辑缓冲，输入负号、小数点或暂时清空时不会每帧重写；非法值不会应用到绘图区。
- 拖动或缩放进入手动查看，新采样不抢回视角；“回到最新”恢复跟随。双击绘图区延续恢复跟随行为。
- 历史范围按数据版本缓存；绘图点按数据版本、首末点、视口和绘图宽度缓存，静止画面复用压缩结果。追加、清空和限长裁剪使相应缓存失效；压缩保留峰谷。
- 周期性实时重绘间隔设为 1/60 秒；暂停后停止图表的周期性重绘；既有 SVD 请求、后台操作及状态通知仍按原逻辑刷新。鼠标、输入和窗口事件仍可触发刷新，此设置不是对硬件采样率的限制，也不是测得的实际帧率。

## 外观

保留柔和粉色、粉白和淡紫点缀，以及深浅主题和状态语义颜色。按最终要求移除二次元装饰及其开关，不绘制猫耳或花朵，不增加素材或动画。

## 涉及文件

| 文件 | 主要修改 |
| --- | --- |
| `src/ui/table_plugin/tree.rs` | 节点注释、旧配置迁移、注释保存与兼容测试 |
| `src/ui/table_plugin/panel.rs` | 九列表格、固定单元格、拖拽列宽、编辑/复制/搜索与交互测试 |
| `src/ui/chart_plugin/panel.rs` | 外置图例、工具栏、范围编辑缓冲、跟随与手动视图、显示缓存调用 |
| `src/ui/chart_plugin/legend.rs` | 数据版本、历史范围增量缓存、绘图缓存与长曲线测试 |
| `src/ui/theme.rs` | 柔和粉色调色板 |
| `src/ui/control_bar.rs` | 可换行控制栏 |
| `src/app.rs` | 60 Hz 周期重绘、可选本地配置测试 |
