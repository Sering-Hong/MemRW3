# 通用 PID 在线调试实施计划

已确认：不指定轴；不改固件；一组PID、每轮只改一个增益。复用已交付的 MemRW3 读写接口，新增主机会话与回滚管理，不增加依赖。

- [x] 添加 Python PID 会话模块：显式绑定Kp/Ki/Kd、目标、反馈和输出，保存基线及变量身份；每项增益由调用方提供最大单轮改变量，不臆测物理范围。
- [x] 提供 pid_begin / pid_snapshot / pid_apply / pid_accept / pid_rollback / pid_end 六个MCP工具。每次写入前检查当前软件会话、变量身份、数据新鲜度、运行状态、安全条件及GUI权限；已有未处理试验时不追加修改。
- [x] 基线先落盘，再调用已有单参数写入。只有读回verified后进入观察；接收基线与回滚均需再次核验。未知、超时、失联、外部修改不盲目回滚。
- [x] 单文件锁、原子保存、唯一request_key、调参最小间隔和最小观察时间；不运行后台自动写入或假装硬实时保护。
- [x] 标准库无硬件测试覆盖正常闭环、回滚、过期/故障拒绝、外部修改、重复请求及不确定状态。同步通用设计、真实固件参考、采样/延迟预算与待补信息。

边界：不提供三参数原子提交、不回写PID积分状态、不自动清故障/使能/运动/发射；网络失联期间的安全退出与看门狗需要固件实现。调参数据的获取只读现有采样；实际运动与具体增益修改需另有人工授权。

执行结果：140项Rust、13项PID模拟和8项MCP测试通过；具体接口、限时与未实现项见 PID在线调试方案.md。未连接MCU。

真实GUI与MCP stdio自检已通过，版本2.1.0共14工具，写入默认关闭；未启动真实PID试验。
