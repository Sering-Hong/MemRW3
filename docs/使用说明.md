# MemRW3 详细使用说明

适用版本：Enhanced Pink（2026-10-20 功能基线，2026-10-24 恢复整理）。适用人群：需要通过调试探针观察 MCU 变量、调整参数、记录波形的使用者。

## 1. 安装、启动与准备

### 1.1 Windows 安装版与便携版

优先从 GitHub Releases 下载 Setup EXE，双击后按[安装说明](安装说明.md)操作。安装器会先检查运行环境，再安装并建立粉色快捷方式。以下也适用于便携版。

将整个压缩包解压至固定位置后运行 `MemRW3.exe`，不要直接在压缩软件中运行。本地已部署在 `D:\MemRW3`；桌面 `MemRW3` 快捷方式指向该目录。`assets/MemRW3-pink.ico` 用于桌面图标，程序窗口图标已嵌入。

双击或用 PowerShell 执行“创建桌面快捷方式.ps1”可以重建快捷方式。移动目录后重新运行该脚本。若系统限制脚本执行，可在文件资源管理器中为 `MemRW3.exe` 手动创建桌面快捷方式，并在属性中选择 `assets/MemRW3-pink.ico`。

### 1.2 硬件与固件

准备已上电的目标板、调试探针和与当前固件对应的 AXF/ELF 文件。SWD 常用接线包括 SWDIO、SWCLK、GND，按探针和板卡要求连接参考电压及复位线；电气接线以各自硬件资料为准。连接前关闭正在占用同一个探针的其他调试软件。

监控变量依赖 ELF/DWARF 调试信息。Keil 工程应在外部 Keil 中启用调试信息后正常编译，再选择生成的 AXF；本软件不负责调用 Keil 编译。只有 HEX/BIN 通常无法提供变量树。重新编译后必须重新加载对应文件，避免用旧地址读写新固件。

## 2. 界面与连接

左侧 Activity Bar 切换 Chart、Table 和 Debug；顶部控制栏负责连接、开始/暂停、复位、烧录与配置。每个插件可以单独暂停，也可以 Pop out 为独立窗口；Pop in 返回主窗口。

1. 打开“设置”，选择准确的 MCU 型号。
2. 选择 SWD/JTAG、探针和速度。连接不稳定时可降低速度后重试。
3. 点击“连接”，确认状态进入已连接。
4. 连接只建立通道；点击全局“开始”后才请求采集。

全局“暂停”停止采集，并保留已显示数据。插件自己的“暂停插件”影响该插件的更新与交互，不能代替全局采集控制。Debug 的“暂停/继续”控制 MCU 是否运行，与采集暂停含义不同。

## 3. 加载变量与建立监控

点击 Chart、Table 或 Debug 的“打开变量树”，选择 `.axf`/`.elf` 并点击“加载”。在树中查找并展开需要的变量。右侧 Basic 显示原始 DWARF 信息，Extend 提供扩展解释属性；修改类型或地址前先核对固件定义。

- 单个数值绘图：选中标量，填写曲线名和颜色，点击“添加到 Chart”。
- 表格观察：选中标量、结构体或数组，填写显示名，点击“添加到 Table”。
- 多层结构：在 Table 展开父节点，查看实际叶节点；采集勾选决定对应变量是否参与读取。
- 固件重编译：停止采集并重新加载 ELF，可用“追踪”更新已添加变量地址，再检查监控项目是否仍对应目标固件。

静态地址变量用于 Chart/Table；函数运行栈内的局部变量应在原有 Debug 面板中暂停目标后查看。编译优化可能消除或折叠变量，导致无法找到或显示不可用。

## 4. Watch 表格式变量查看器

Table 默认显示 Watch 表格，列包含采集、名称、类型、地址、当前值、刷新频率、写入和操作。

### 4.1 查看和筛选

展开/折叠结构体与数组，使用“展开全部”“折叠全部”快速整理。搜索框支持名称或十六进制地址；匹配项的祖先会保留，方便定位层级。叶节点的刷新频率可在 1–60 Hz 范围设置，它控制表格显示刷新，不代表底层实际采样率。

勾选父节点可以批量切换后代，叶节点可独立选择。相同变量可以同时出现在 Chart 和 Table；表格显示最新值，曲线保留历史。

### 4.2 写入变量

在标量的写入框输入新值，点击“写”/“写入”或按 Enter 提交。整数和浮点数按当前 ExtendType 解析与检查范围，例如 `u8` 的有效范围为 0–255。提交错误时根据界面提示修正。

写入对象是目标 RAM 中的实时变量。固件下一次赋值可能覆盖结果，复位后也可能恢复初值；这不会修改 C/C++ 源码、Keil 工程或固件文件。调整控制参数时先确认变量、单位和目标运行状态。

### 4.3 同时查看数值与曲线

在 Table 右上角点击 Pop out，将 Watch 弹出为独立窗口；主窗口切回 Chart 并调整两个窗口的位置。切换插件不会停止 Chart 的数据摄取。完成后通过 Pop in 收回窗口。

### 4.4 SVD 寄存器

需要寄存器时启用“显示 SVD 寄存器”，加载与 MCU 匹配的 `.svd`/`.xml`。展开外设查看寄存器地址、位宽、权限和字段。勾选可读寄存器并设置 1–30 Hz 刷新频率；寄存器读取采用独立调度。只读寄存器不提供写入控件，可写寄存器按界面提供的十六进制/十进制格式提交。

## 5. 曲线采集与完整历史

### 5.1 从开始保留到结束

新曲线默认启用“保留全部采样”，加载旧配置也默认采用完整历史。开始后持续追加采样点，不再达到固定点数就丢弃最早数据。全局暂停和再次开始保留内存中的已有曲线；“清空”会删除当前图表数据并重新记录。

“查看全部”恢复自动 X 轴并显示从开始到当前的完整范围。固定 X 轴窗口、拖动、缩放只是改变查看范围，不会删除早期点。双击图表恢复自动显示；也可通过缩放查看某一时段。

### 5.2 性能与保存边界

绘图按可视宽度压缩显示点，并保留每段最大值、最小值及首尾点。原始历史仍保存在内存，游标、FFT、CSV 不使用绘图压缩后的点集。保留全部意味着内存随时长与曲线数增长，并非无限容量。

单条曲线的基础时间戳与数值约为每点 16 字节，100 万点的样本载荷约 16 MB，实际占用还包括容器容量、渲染与其他程序数据。内存紧张时应降低采样速度、减少变量或分段保存。暂停时右键图例打开属性，可以关闭“保留全部采样”并选择限长缓冲；这样会按容量裁剪旧数据。

关闭程序后内存历史丢失；配置文件只保存设置，不保存波形。重新连接、换 ELF、加载配置、烧录等操作可能重置采集状态，操作前先保存所需记录。断开后保留最后画面不等于永久存档。

### 5.3 采样速度与 FFT

控制栏的延迟控制读取循环间隔，0 表示尽可能快。显示刷新率与采样率不是同一个概念。更多变量、较慢 SWD、目标暂停或繁忙会影响实际速度。

点击 FFT 显示频谱，选择 Rectangular、Hann、Hamming、Blackman 窗函数及 4–65536 点，分析数据来自历史尾部。程序处理暂停形成的不连续段，并对采样抖动进行线性重采样；这不能代替严格的定时采样仪器。时域和频域分别支持 X、Y、Both 缩放。

## 6. CSV 日志与配置

### 6.1 CSV

在开始前选择 CSV 路径。开始时创建文件，写入 `timestamp` 和各曲线名称作为表头，后续写入数据；暂停后关闭写入器。需要完整持久记录时，应先选 CSV 再开始。

**每次从全局暂停再次开始，都会重新创建并覆盖所选的同一个 CSV 文件。** 内存曲线会保留，但磁盘日志不会自动追加上一段。要保存多段，请在再次开始前换新文件名，例如 `capture_01.csv`、`capture_02.csv`。Debug 断点导致的暂时停止 Stream 与手动全局暂停不同，不会伪造低频 Chart/CSV 数据。

### 6.2 JSON 配置

保存配置可记录探针设置、ELF 路径、变量池、曲线/表格设置及各插件配置。加载前停止采集并断开目标。迁移电脑后检查 ELF 和源码根目录是否仍有效，重新选择路径。不要把自己的固件、含设备信息的配置或采样日志提交到公共仓库。

## 7. 手动烧录固件

连接正确目标后点击“烧录固件”，选择 ELF/AXF、HEX、BIN 或 UF2，检查确认框内的芯片和文件，再开始。程序暂停采集，完成写入校验后复位目标。BIN 使用所选芯片的启动 Flash 基址；需要非默认布局时应使用带地址的格式或合适的外部工具。

烧录后重新加载与固件匹配的 ELF，检查变量地址，然后再开始监控。此版本通过界面触发烧录；没有新增的 F8 烧录绑定。

## 8. 原有 Debug 调试器

此版本保留上游 Debug：用于查看源码、反汇编、断点、调用栈、局部变量和 CPU 寄存器。源码视图用于调试浏览；修改固件请回到外部 IDE 编译，再按上一节烧录。

1. 加载带调试信息且匹配目标的 ELF，连接探针。
2. 点击全局“开始”，启用 Debug 插件。
3. 选择 Attach（保持目标状态）或 Reset（复位并暂停），再点击 Debug 的“启动”。
4. 若构建时的源码路径无效，设置本机源码根目录进行映射。
5. 双击可执行源码行或汇编行设置/取消硬件断点。暂停后查看栈帧与局部变量。
6. 使用继续、暂停、源码步入/步过/步出；有内存地址的标量局部变量可在暂停时写入。

| 原有 Debug 快捷键 | 含义 |
|---|---|
| F5 | 调试继续运行 |
| F6 | 暂停 MCU |
| F9 | 切换光标断点 |
| F10 | 源码步过 |
| F11 | 源码步入 |
| Shift+F11 | 源码步出 |

快捷键在调试上下文和对应状态下生效；文本输入期间不会触发调试快捷键。**F5 在此版本中是原有 Debug 的“继续”，不是新加的全局“开始”。F7 编译、F8 烧录和内置 Keil 后台编译已经撤回。**

目前使用 core 0，硬件断点数量受 MCU 限制；优化代码可能出现跨行或局部变量不可用。MCU Halt 时 Chart 停止接收高速流，Table 仍可约 1 Hz 更新最新值；继续后按采集意图恢复。

## 9. 常见问题

| 现象 | 检查和处理 |
|---|---|
| 找不到探针/连接失败 | 接线、供电、驱动、是否被其他 IDE 占用、MCU 型号、SWD/JTAG；降低速度重试 |
| 变量树为空或缺变量 | 是否为包含调试信息的 ELF/AXF；是否重新编译；是否被优化掉；局部变量请在 Debug 暂停后查看 |
| 数值不对/无法写入 | ELF 与板上固件是否一致；变量地址/类型是否正确；固件是否立刻覆盖写入值 |
| 看起来只有最近几秒 | 点击“查看全部”，检查是否只固定了 X 轴窗口，再检查曲线“保留全部采样”是否启用 |
| 内存随采样上升 | 完整历史的预期行为；减少变量/采样率，分段记录，或暂停后改用限长缓冲 |
| CSV 只剩最后一段 | 同一个文件被再次开始覆盖；开始下一段前更换文件名 |
| 保存配置后找不到历史 | 配置不包含样本；应在采集前开启 CSV |
| Debug 无源码 | ELF 缺 DWARF 或记录了另一台机器路径，设置源码根目录映射 |
| 断点失败/单步异常 | 检查硬件断点容量、固件与 ELF 一致性、优化级别及目标异常状态 |
| 桌面图标或路径不对 | 解压全部 assets，运行创建快捷方式脚本；确认目标为当前目录的 MemRW3.exe |

## 10. 建议的完整操作流程

外部 IDE 修改并编译固件 → 连接探针并手动烧录 → 加载匹配 AXF/ELF → 添加 Watch/Chart 变量 → 选择新的 CSV 文件 → 点击开始 → 观察表格与波形 → 暂停 → 查看全部 → 保存配置并确认 CSV 已落盘。
