# 界面定制、调试助手与 Claude 接入（2026-11-12）

## 1. 变量表：名称完整显示、列可隐藏

- **长文本换行**（工具栏勾选，默认开）：参数名称和中文注释超出列宽时自动换行，行高随内容增加。关闭后恢复单行，悬停可看完整路径、显示名和注释。
- **分组标题跨列**：没有注释的分组行（如“01 调参控制 g_dart_tune（只在手动模式生效）”）横跨名称和注释两列。要给分组加注释：右键名称 →“编辑中文注释”。
- **适配列宽**：按当前展开的内容一次调整所有列。旧配置（JSON 里没有列宽）首次加载时自动适配一次。单列仍可拖动表头分隔线，或双击分隔线适配。
- **列显示/隐藏**：工具栏“列”菜单，或右键任一表头。可隐藏采集、注释、类型、地址、当前值、刷新频率、写入值、操作；“参数名称”列不能隐藏。“精简”一键只留名称/注释/当前值/写入。
  - 隐藏“写入值”列后，操作列不再显示“写入”按钮，避免把看不见的旧输入写下去。
- **记忆**：列显示和换行设置自动保存到 `%LOCALAPPDATA%\MemRW3\ui-prefs.json`，下次启动沿用；“保存配置”时也写进调参 JSON（`hidden_columns`、`wrap_text`）。加载的 JSON 里有这两项时以 JSON 为准，没有（旧配置）则沿用本机设置。

## 2. 图表曲线列表

曲线名称自动换行，下方用小字显示中文注释；列表左边缘可拖宽到 900 像素。

## 3. 工作区布局

- **默认只显示图表 + 变量**两个面板；调试面板点最左侧的虫子图标显示。图标再点一次隐藏对应面板，至少保留一个。
- **拖动换位**：按住面板标题（左侧有六个点的握把）拖到另一个面板上松开，两者交换位置。
- **排列方式**（“工作区布局”菜单）：上方主区 + 下方并排、左侧主区 + 右侧堆叠、全部左右并排、全部上下堆叠。
- 面板标题栏：隐藏、最大化/还原、暂停插件、独立窗口。分隔条可拖动调整比例。
- **记忆**：布局自动保存到本机 `ui-prefs.json`，下次启动恢复；“保存配置”也会写进 JSON。加载带 `workspace` 的 JSON 用 JSON 里的布局；旧 JSON 没有该字段时保持当前布局。背景强度/透明度仍以本机外观设置为准。
- 旧配置兼容：`workspace` 里没有 `hidden` 时按默认隐藏调试面板；没有 `arrangement` 时按原 `chart_on_top` 排列。

## 4. 左侧“调试助手”栏

最左侧底部的扳手图标开关，右边缘可拖宽（220–560 像素），开关和宽度自动记住。

| 区域 | 用途 | 说明 |
|---|---|---|
| 目标状态 | 一眼看清未连接 / 已连接未采集 / 运行中采集中 / 已暂停 / LockUp / 烧录中 | 暂停原因、PC、当前函数只有在调试面板“启动调试”后才有；未启动调试器时只报告连接与采集状态 |
| 变量快速搜索 | 按名称、中文注释或 `0x` 地址查已加载变量，显示当前值，可“加入图表”或复制路径 | 只搜已加载的变量；“从 ELF 添加新变量…”打开变量树 |
| 表达式 Watch | 对已加载变量做 `+ - * /`、括号、`abs/sqrt/min/max` 运算，如 `target - speed` | 变量名写完整路径或唯一的末尾字段；变量需在变量表勾选采集或已加入图表才有值；各变量不保证同一采样时刻；随“保存配置”保存（JSON 顶层 `sidebar`） |
| 断点与调用栈 | 断点是否生效、硬件上限、暂停时的调用栈 | 只读摘要，增删断点和单步仍在调试面板 |
| 内存查看 | 输入 `0x` 地址或变量名，读 4–256 字节，十六进制 + ASCII 显示，可约 0.5 秒自动刷新 | 只读；复用寄存器读取通路。读外设寄存器地址可能有读副作用，RAM/Flash 没有 |

候选功能与取舍：数据断点、RTT 终端、时间线/代码剖析、带指针解引用的表达式需要新的硬件通路，本次未做；SVD 外设寄存器（变量面板勾选“显示 SVD 寄存器”）、CPU 寄存器和局部变量（调试面板）原本已有，未重复实现。

## 5. Claude Code 接入 MCP

MemRW3 启动后自动开启本机 AI 接口；`tools\memrw3_mcp.py` 是标准 stdio MCP server（只用 Python 标准库），共 14 个工具：`list_sessions`、`get_status`、`list_variables`、`read_variables`、`get_history`、`get_write_permissions`、`get_write_result`、`write_variable`、`pid_begin/snapshot/apply/accept/rollback/end`。

**项目级配置（已放在 `G:\STM32_ALL\RM\.mcp.json`）：**

```json
{
  "mcpServers": {
    "memrw3": {
      "type": "stdio",
      "command": "C:\\Python314\\python.exe",
      "args": ["-u", "G:\\STM32_ALL\\RM\\MemRW3-2.2.1-pink.1\\MemRW3-2.2.1-pink.1\\dist\\MemRW3\\tools\\memrw3_mcp.py"]
    }
  }
}
```

在 `G:\STM32_ALL\RM` 下启动 Claude Code，首次会询问是否信任项目里的 `memrw3` 服务器，批准一次即可。也可以用命令添加到个人配置（任何目录都能用）：

```bash
claude mcp add --scope user memrw3 -- C:\Python314\python.exe -u "G:\STM32_ALL\RM\MemRW3-2.2.1-pink.1\MemRW3-2.2.1-pink.1\dist\MemRW3\tools\memrw3_mcp.py"
```

检查：

```bash
claude mcp list
```

使用顺序：先打开 MemRW3 并加载配置 → 让 Claude 调 `list_sessions` / `get_status` → `list_variables` 找变量 ID → `read_variables` / `get_history` 读数。

**安全约束未放宽**：没有连接探针、暂停、复位、烧录、任意地址读写的工具；`write_variable` 仍要求预期旧值比较、唯一 `request_key`、写后回读，结果要用 `get_write_result` 查询，`uncertain` 不自动重试；PID 工具仍是单轮单增益、限步长、可回滚。写入会真实改变 MCU 参数，机构可能动作，只在你明确要求时让 Claude 写。
