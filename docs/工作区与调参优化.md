# 工作区与调参优化

## 使用

启动唯一程序：`dist/MemRW3/MemRW3.exe`，原桌面快捷方式和 Codex MCP 路径不变。

- **背景设置**：指定樱花初音壁纸已内置；背景强度默认 30%，面板不透明度默认 90%。0% 背景强度隐藏图片，不影响基本主题。图片按比例居中铺满，窗口比例不同会裁切边缘。
- **工作区布局**：默认上图表、下方左变量右调试；拖动分隔条调整大小，菜单切换排列或交换区域。各区可最大化、还原、独立显示；恢复默认布局会退出最大化。布局操作不改变 MCU 运行状态。
- **加入图表**：变量行“加入图表”，或右键参数名；分组可一次加入所有可读取数值字段。重复添加定位已有曲线，原 Watch 保留；加入后收集新样本，不补造加入前的历史。
- **显示格式**：变量区选择十进制/常规、十六进制、二进制或科学计数法。仅改变显示，写入仍按原有类型和十进制校验规则处理。
- **变化高亮**：实际数值改变后短暂高亮；初次采样不高亮。超过 2 秒没有新采样标记陈旧，断开时显示缓存提示。没有样本不代表值为零，也不凭无数据推断硬件故障。
- **A/B 区间统计**：勾选后输入或拖动 A/B 时间；Shift+点击曲线设 A，Ctrl+点击设 B。显示样本数、最小值、最大值、均值、峰峰值和时间差，按原始历史计算，有效区间包含端点，反向 A/B 自动按前后范围处理。
- **历史 CSV**：导出全部或 A/B 区间。以导出时快照后台写文件，每条样本保留所属变量的时间，不强行对齐或插值。导出仅含当前内存保留的历史；设置限长缓冲的曲线无法恢复已淘汰数据。原有实时 CSV 记录仍保留。导出沿用图表的 f64 数值历史，不作为 64 位整数逐位备份。
- **参数修改记录**：工作区工具栏打开，记录变量表与 AI 接口写入的时间、来源、完整路径、旧值、新值、结果和回读状态，可导出 CSV。手工旧值来自最新值缓存，手工成功表示 Worker 返回写入成功，标为未回读验证；AI 同时保留调用者预期旧值和底层可用的真实预读/回读原始位。只有验证一致才标“已回读验证”。记录仅保留本次运行，关闭程序前需要导出；不包含寄存器、调试器局部变量或其他软件的写入。

背景显示强度和面板不透明度调整后自动保存到 `%LOCALAPPDATA%\MemRW3\appearance.json`，停止调整约 400 ms 后写入，正常退出时补存尚未完成的调整；下次启动自动恢复。已有本机外观偏好时，加载调参 JSON 不会覆盖透明度。未设置本机偏好时可沿用配置中的外观；修改后会自动记住。保存失败时界面显示中文原因，不宣称保存成功。布局仍通过“保存配置”保存；旧 JSON 无需修改固件或重新生成。已有名称、中文注释、地址、类型和列宽兼容保留。

## 可复现构建

当前 Windows MinGW 环境使用 Rust 工具链内置链接器；无需改 Cargo 配置：

```powershell
$env:PATH='C:\Users\hqzzz\.cargo\bin;C:\ClionToolchains\mingw64\bin;'+$env:PATH
cargo fmt --all -- --check
cargo rustc --release --locked --offline --bin MemRW3 -- -C linker=C:/Users/hqzzz/.rustup/toolchains/stable-x86_64-pc-windows-gnu/lib/rustlib/x86_64-pc-windows-gnu/bin/self-contained/x86_64-w64-mingw32-gcc.exe -L native=target/ui-link-libs
```

`target/ui-link-libs` 是本机已有的链接兼容目录；这些绝对路径仅说明当前验证环境，不是其他电脑的默认安装要求。程序运行不需要 Rust。
