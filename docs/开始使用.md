# MemRW3 当前唯一版本

**2026-11-12 新功能**（详见 [界面定制与调试助手](docs/界面定制与调试助手.md)）：

- 默认只显示图表 + 变量；点最左侧图标显示/隐藏面板，拖面板标题可交换位置。
- 变量表“列”菜单或右键表头隐藏地址等列；“长文本换行”让名称和注释完整显示；“适配列宽”一键调整。
- 最左侧底部扳手图标打开“调试助手”：目标状态、变量搜索、表达式 Watch、断点/调用栈、内存查看。
- 布局、列和侧栏设置自动记住，不用每次“保存配置”。
- Claude Code 接入：MCP server 在本目录 `tools\memrw3_mcp.py`，配置方法见 [界面定制与调试助手](docs/界面定制与调试助手.md) 第 5 节。

双击本目录 `MemRW3.exe`，或运行“创建桌面快捷方式.ps1”后使用桌面快捷方式。

- 拖动分隔条或使用“工作区布局”调整面板。
- “背景设置”调整壁纸强度和面板不透明度。
- 变量行“加入图表”，或右键变量名/分组，一键画曲线。
- 图表勾选“A/B 区间统计”，可导出全部历史或选定区间 CSV。
- “参数修改记录”查看并导出手工/AI 变量写入结果；未回读验证与已验证明确区分。
- 背景强度和面板不透明度调整后自动记住，下次启动恢复；加载调参 JSON 不覆盖本机外观。

AI 接口启动即自动可用，全部已加载数值变量默认可读写，无需勾选或授权。原有 CSV、FFT、源码调试和 PID 会话/回滚保留。

操作与验证见 [工作区与调参优化](docs/工作区与调参优化.md)。
